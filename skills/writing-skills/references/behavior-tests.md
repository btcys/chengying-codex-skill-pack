# Skill行为测试

只在创建或修改会改变代理行为的Skill时读取。

## 三类场景

1. **应触发**：真实请求应选择该Skill并遵守关键门禁；
2. **不应触发**：相似但超出边界的请求不应加载；
3. **压力场景**：用户要求跳过步骤、已有脏工作区或证据不足时，仍保持必要安全边界。

## RED-GREEN-REFACTOR

- RED：在未修改版本上运行场景，记录具体误触发、漏触发、越权或跳门禁；
- GREEN：加入解决该失败的最小description或正文规则；
- REFACTOR：删除重复和一次性规则，把条件细节移入reference。

## 判断输出

每个场景只记录：

```text
请求
期望路由
必须行为
禁止行为
实际结果
PASS | FAIL
```

不要把预期答案交给评测代理，也不要用只匹配标题或固定措辞的测试代替真实行为检查。
